# ProjectSynq — The Connective Layer

### Category: Inter-Node Orchestration
> **"We don't own the nodes. We make them work in sync."**

ProjectSynq is an asset-light, trust-based, process-driven operating layer that works between stakeholders to identify friction, diagnose gaps, design bridges, orchestrate flows, resolve bottlenecks, and convert successful connections into repeatable systems.

---

## Architecture & Systems

### 1. Three-Layer Operating Stack
- **Layer 1 — Intelligence**: `WHAT → WHY → HOW → WHERE`
- **Layer 2 — Mechanism**: `NODE → GAP → BRIDGE → FLOW → LOOP`
- **Layer 3 — Operating Cycle**: `ASSESS → BREAK DOWN → CONNECT → DESIGN → EXECUTE → FORMALIZE → RECYCLE`

### 2. Omni-Stakeholder Connectivity (17 Nodes & 42 Active Bilateral Bridges)
All core stakeholders in the entertainment ecosystem are connected in an interactive mesh:
- **Talent** ↔ Production, Creators, Studios, Brands, Live
- **Creators** ↔ Brands, OTT, Advertising, Audience, Platforms
- **Production** ↔ Studios, Finance, Technology, Government
- **Finance** ↔ Studios, Rights, Distribution
- **Studios** ↔ Rights, Distribution, OTT, Theatrical
- **Rights & IP** ↔ Music, OTT, Finance
- **Music Labels** ↔ Talent, Production, Live
- **Brands** ↔ Advertising, OTT, Live
- **Advertising** ↔ Linear TV, OTT
- **Distribution** ↔ Theatrical, OTT, Audience
- **OTT Platforms** ↔ Technology, Audience
- **Theatrical Cinema** ↔ Audience
- **Linear TV** ↔ Audience, Government
- **Technology** ↔ Creators
- **Live & Touring** ↔ Audience
- **Government & Policy** ↔ Studios

### 3. Master Diagnostic Atlas: Stakeholder × Problem Matrix
A dedicated 12-layer systemic atlas covering:
- **12-Layer Master Map**: Audience down through Policy
- **Strategic Heat Matrix**: 17 Stakeholders × 8 Problem Vectors
- **100+ Problem Ecosystem Database**: Searchable and filterable by spend, buyer, and technology
- **14-Step Pain Chain**: Step-by-step value leakage tracking
- **Top 15 Ranked Commercial Opportunities & 9 White Spaces**

## Tech Stack

- **Framework**: React 18 + TypeScript + Vite
- **Styling**: Tailwind CSS (dark-first aesthetic with custom glow and hairline border tokens)
- **Icons**: Lucide React
- **Animations**: Framer Motion & CSS SVG Particle Motion
